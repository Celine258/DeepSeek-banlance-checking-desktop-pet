# DeepSeek 余额桌宠

一个浮在桌面上的透明小角色。左键点它，它睁开眼睛、露出坏笑，并在左上方弹出一句关于 DeepSeek 余额的话。右键点它，换角色、换大小、填 API Key。

- 窗口是**真透明**的，人物以外的区域完全不挡鼠标，桌面图标照样能点
- 余额通过官方接口实时查询，API Key 只存在你本机
- 角色素材是热加载的：往文件夹里丢图，右键菜单立刻就能选，不用重启

---

## 一、怎么跑起来

### 1. 装 Node.js（只装一次）

到 <https://nodejs.org/> 下载 **LTS 版本**，一路下一步装完就行。

### 2. 把角色图导进去

把你准备好的 PNG 图片（每个角色两张：`_闭眼` / `_睁眼`）丢进 **`待导入`** 文件夹，然后双击 **`导入素材.bat`**。

它会自动按文件名配对、分到 `assets/characters/角色N/` 里，并且做两件事：

- **体检**：透明底有没有抠干净、两张图尺寸是否一致、人物位置对不对得齐、是不是只改了脸。任何一项不对都会直接标出来。
- **自动对齐**：算出「点击图」相对「平时图」需要平移和缩放多少，直接生成对齐好的新图（原图备份在 `_原始/`）。

第二件事很重要。程序是把两张图**叠在同一个位置**、点击时只把上面那层透明度调上来的，所以两张图里人物只要有 1 像素的偏差，点击时整个人就会抖一下。自动对齐就是专门治这个的。

以后想重新对齐（比如你换了图），双击 **`对齐素材.bat`** 就行。

想先跳过这步也行，程序会用内置的灰色剪影占位图，功能完全一样。

### 3. 双击 `启动.bat`

第一次会自动下载依赖（几百 MB，几分钟），下完就自己启动了。之后再双击就是秒开。

> 国内下 Electron 经常卡住，启动脚本里已经自动配好了国内镜像，正常情况下不用管。
> 如果你挂了代理反而更慢，用记事本打开 `启动.bat`，把里面两行 `set "ELECTRON_..._MIRROR=..."` 删掉再试。

### 4. 填 API Key

到 <https://platform.deepseek.com/api_keys> 新建一个 Key，然后 **右键角色 → 设置 API Key**，粘进去，点「测试连接」确认能用，再点保存。

## 二、怎么用

| 操作 | 效果 |
| --- | --- |
| **左键点角色** | 切到「睁眼邪笑」那一帧，左上方弹出余额气泡，几秒后自动收起 |
| **按住左键拖动** | 把角色拖到桌面任意位置（位置会记住） |
| **右键点角色** | 打开菜单：换角色 / 换大小 / 各种开关 / 设置 / 退出 |
| **点任务栏里的蓝色小圆点** | 从托盘菜单里找回角色、刷新余额、退出 |

右键菜单里各项的意思：

- **角色列表** —— 你在 `assets/characters` 里放的角色，点一下立刻换。
- **刷新余额** —— 手动查一次。
- **气泡常显** —— 打开之后气泡不再自动消失，一直挂着（适合想一直盯着余额的时候）。
- **大小** —— 小 / 中 / 大，换的时候角色右下角的位置不动。
- **总是显示在最前面** —— 关掉的话，切到别的窗口时桌宠会被盖住。
- **透明区域不挡鼠标** —— 默认开着。如果发现桌宠点不动、或者反过来挡住了桌面，来这里切一下。
- **开机自动启动** —— 登录 Windows 后自动把桌宠拉起来。
- **打开素材文件夹 / 打开配置文件** —— 直接跳到对应位置。

## 三、角色素材

**现在里面还没有你的图，显示的是一个灰色剪影占位图（它也有闭眼/睁眼两帧，方便你先看效果）。**

导入只要两步：图片丢进 `待导入/`，双击 `导入素材.bat`。文件名里带「闭眼」和「睁眼」就行，比如 `银狼_闭眼.png` / `银狼_睁眼.png`。

如果想手动摆，也可以自己往 `assets/characters/角色1/` 这样的文件夹里放 `idle.png` 和 `active.png`。

详细规格（画布尺寸、对齐要求、抠图办法、自检方法）都写在 **[素材规格.md](素材规格.md)** 里了。

一句话版本：**两张图必须一样大、人物必须一样位置，只改脸。**

## 四、配置文件

存在这里：

```
C:\Users\<你的用户名>\AppData\Roaming\DeepSeekPet\config.json
```

里面记着 API Key、当前角色、大小、窗口位置这些。删掉这个文件就恢复默认（API Key 也就没了）。

> API Key 是**明文**存在这个文件里的——桌面小工具基本都是这么干的，但你要知道这件事。别把这个文件发给别人。

## 五、目录结构

```
deepseek-pet/
├── 启动.bat                 双击就能跑
├── 导入素材.bat              双击自动分拣角色图 + 体检 + 自动对齐
├── 对齐素材.bat              双击重新对齐已经导入的角色图
├── .gitignore               仓库里不包含 node_modules 等
├── 待导入/                   把角色图丢这里
├── 素材规格.md              你自己做图时的规格说明
├── README.md                就是本文件
├── package.json
├── main.js                  主进程：窗口 / 托盘 / 右键菜单 / 余额请求
├── preload.js               主进程 ↔ 界面 的唯一通道
├── lib/
│   ├── config.js            配置读写
│   ├── deepseek.js          余额接口
│   ├── characters.js        扫描角色素材
│   ├── hitmask.js           算角色轮廓，用来做鼠标穿透
│   └── png.js               纯手写的 PNG 生成器（托盘图标 + 占位角色）
├── renderer/
│   ├── pet.html / .css / .js        桌宠本体
│   └── settings.html / .js          API Key 设置窗
├── tools/
│   └── import-assets.js     素材分拣 + 体检脚本
└── assets/characters/角色1 ~ 角色4/   ← 素材最终落在这里
```

## 六、想打包成 exe

```
npm run dist
```

会在 `dist/` 下面生成一个 `DeepSeekPet.exe`，双击即用，不用装 Node.js。第一次打包会下载打包工具，慢一点。

## 七、出问题了怎么办

**角色没出现 / 显示的还是灰色剪影**
素材没被认出来。检查文件名是不是真的叫 `idle.png`（Windows 默认隐藏扩展名，很容易变成 `idle.png.png`），以及是不是直接放在角色文件夹里。

**点角色没反应**
右键菜单 → 把「透明区域不挡鼠标」关掉试试。如果关掉就能点，说明是轮廓判定的问题，把角色图发我看看。

**气泡里写「还没填 API Key」**
右键 → 设置 API Key。

**气泡里写「连不上 api.deepseek.com」**
网络或代理问题。这个请求要能直连 `api.deepseek.com`。

**点角色的时候，人物会整体抖一下 / 出现重影**
两张素材图没对齐。双击 `对齐素材.bat`，它会自动修好（原图备份在角色的 `_原始/` 文件夹里）。修完要重启桌宠才会重新加载图片。

**按住左键不动，角色自己往右下角滑**
这是 Windows 上 `resizable: false` 窗口移动时尺寸被系统改掉的已知问题，已经在 1.0.1 里修掉了（窗口改成可 resizable 但去掉调整边框，另外移动后会核对尺寸）。如果你还遇到，把现象告诉我。

**换了角色之后窗口歪了 / 跑到屏幕外面**
右键 → 换回原来大小，或者直接拖回来。窗口位置存在配置文件里，也可以删掉配置文件重来。

**拖动的时候人跟手不一致**
只在你同时接了多个显示器、而且缩放比例不一样的时候可能出现。告诉我屏幕配置我来调。
